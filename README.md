# Koshade

ReShade installer for custom Roblox clients with support for custom shaders and presets.

## Features

- Automatic ReShade installation to client directory
- Built-in shader packs (crosire, FXShaders, qUINT)
- Support for custom paths and executable names
- Easy hotkey configuration
- Automatic cleanup on uninstall

## Installation

1. Download `KoshadeSetup.exe`
2. Run the installer
3. Follow the on-screen instructions
4. Launch Roblox — ReShade will activate automatically

## Customization

### Presets

Add `.ini` preset files to `Files/Preset/` — they will be available during installation.

## Uninstallation

Run `Uninstall Koshade.exe` from the Start Menu or via Control Panel → Programs and Features.
